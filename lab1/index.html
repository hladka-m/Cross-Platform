Note De Parfum

Кросплатформний застосунок для каталогу елітної парфумерії

Про застосунок

Note De Parfum — це сучасний кросплатформний каталог та довідник парфумерних нот, який працює у браузері на будь-яких пристроях: комп'ютерах, планшетах і смартфонах.

Для створення інтерфейсу використано HTML і CSS, а для взаємодії з користувачем — JavaScript.

Основні функції

  • Перегляд каталогу парфумерних нот та ароматів
  • Швидкий пошук та фільтрація парфумів за нотами
  • Додавання обраних ароматів до списку улюблених
  • Видалення ароматів із власного списку
  • Перегляд детальної інформації про кожен парфум

    Обраний стек технологій

    Для розробки каталогу Note De Parfum використано WebView-підхід, оскільки застосунок реалізовано за допомогою вебтехнологій і він може запускатися у браузері або бути вбудованим у мобільний застосунок через WebView.

    Структура сторінки HTML Семантична розмітка каталогу парфумів та блоків інформації
    Оформлення CSS Стилізація інтерфейсу, адаптивна верстка та візуальні ефекти
    Логіка та інтерактивність JavaScript Обробка дій користувача, фільтрація нот та динамічний вивід
    Архітектурний підхід WebView Можливість запуску як вебсайту та вбудовування в мобільні застосунки
